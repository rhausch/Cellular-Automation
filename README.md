# Cellular-Automation
Showcase of several cellular automation simulations

## Running

No build step or package manager is needed. Serve the `app/` directory with any static file server and open it in a browser:

```
cd app && python3 -m http.server 8000
```

The libraries (AngularJS 1.8.3, ui-router 0.4.3, Bootstrap 3.4.1) are vendored in `app/vendor/`.

## Status

This is old example work kept for reference. It uses AngularJS 1.x, which reached end-of-life in 2022 and has published security advisories that will never be fixed, so do not deploy it as a public-facing application.
